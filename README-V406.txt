خلوتي v406 — إضافة قائمة اختيار نسخ الكتاب المقدس
================================================

ما تم إضافته:
-------------
1. قائمة اختيار نسخ (Version Selector) فوق واجهة الكتاب المقدس
   - AVD (الفصحى · فاندايك)  ← النسخة الافتراضية
   - WEB (English)           ← World English Bible (عامة)

2. الزرار بيظهروا بشكل أزرار مستديرة زي تطبيق دار الكتاب المقدس
3. الاختيار بيتخزن في localStorage عشان يفضل محفوظ
4. عنوان الصفحة بيتغير حسب النسخة المختارة

ملاحظات مهمة:
-------------
- نسختا ESV و ARZ (العامية المصرية) محميتان بحقوق نشر، لذلك مش متوفرين حالياً.
- لو حابة تضيفيهم لاحقاً، الهيكل جاهز (بس محتاجين ملفات النصوص).

طريقة الاستخدام:
---------------
1. ارفعي ملف index.html الجديد على GitHub (استبدلي القديم)
2. أو فكي الـ ZIP ده واستخدمي الملفات
